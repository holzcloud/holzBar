# Competitor research: SaneBar and Vanilla (researched 2026-10-09)

Confidence: stated = vendor docs say so; code = read in source; inferred; unknown = not found after checking the pages below.
Base URLs: SB-raw = https://raw.githubusercontent.com/sane-apps/SaneBar/main/ ; SB-web = https://sanebar.com ; V-web = https://matthewpalmer.net/vanilla/

Key context: SaneBar was sunset on 2026-06-30 (v2.1.88): made free + MIT, "community-maintained", because the developer says macOS 27 breaks menu bar managers. Last release 2.1.91 (2026-09-09). Vanilla is a small, old, closed-source app whose newest documented release is "Vanilla 2.2 - improved compatibility with macOS 26 Tahoe".
