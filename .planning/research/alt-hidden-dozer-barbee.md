# Competitor research: Hidden Bar, Dozer, Barbee (as of 2026-10-09)

Confidence tags: stated = on an official page; code = read in source; inferred = derived; unknown = not found after checking sources below.
Limits: GitHub API/MCP access to the competitor repos was denied in this session, so source files were read via raw.githubusercontent.com and github.com pages only. Barbee is closed source and has no official product website (only the App Store listing, a feedback repo and a personal blog), so many Barbee answers are "unknown". Barbee's own listing is the only primary source; reviews are secondary.
