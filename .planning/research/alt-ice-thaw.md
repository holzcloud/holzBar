# Ice 0.11.12 and Thaw 3.0: competitor research (as of 2026-10-09)

Confidence legend: stated = in README/docs/release notes; code = read in source; inferred; unknown.
Access note: the GitHub API was blocked for these repos, so everything was read through github.com / raw.githubusercontent.com pages (WebFetch, summarised by a small model). Release dates show day and month only on GitHub; years are inferred from context.

Important framing: **Thaw 3.0 is not released.** Latest Thaw stable is 2.0.1 (02 Sep 2026). 3.0.0 exists as alpha (3.0.0-alpha.1 to alpha.7) and beta (3.0.0-beta.1 on 02 Oct, 3.0.0-beta.2 on 07 Oct 2026), macOS 27 only.
