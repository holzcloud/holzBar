## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository → GitHub-hosted runner | Workflow code runs with the repository's GITHUB_TOKEN; the token scope decides what a compromised step could change |
| runner image → build | The image supplies the toolchain; an unpinned selection can silently change the compiler that produces the shipped app |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-01 | Elevation of Privilege | .github/workflows/build.yml GITHUB_TOKEN | medium | mitigate | Top-level `permissions: contents: read`; build and test only read the checkout |
| T-01-02 | Tampering | Xcode selection (.github/actions/select-xcode) | low | mitigate | Exact version pin, `::error::` and exit 1 when missing, re-check of `xcodebuild -version` against the pin |
