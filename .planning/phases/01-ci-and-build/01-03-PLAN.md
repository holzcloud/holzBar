## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workflow_dispatch input / tag name → release shell | An untrusted string enters a job that holds `contents: write`, publishes the binary and pushes to main |
| release job → Casks/holzice.rb on main | The cask is Ruby that Homebrew evaluates on users' Macs; anything spliced into it runs there |
| contributor's Mac → install.sh | A local build signs and installs an app that asks for Accessibility and Screen Recording |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Tampering | .github/workflows/release.yml run blocks (script injection) | high | mitigate | Version only via `env:` (DISPATCH_VERSION, GITHUB_REF_NAME); no expression inside any run block (Task 2 verify); strict regex before first use |
| T-01-06 | Tampering | Cask update sed in release.yml | high | mitigate | Only a regex-validated VERSION (digits, dots, -betaN) and a shasum-produced SHA256 reach the sed replacement, so no quote, slash or Ruby can be injected into Casks/holzice.rb |
| T-01-07 | Tampering | `$GITHUB_ENV` write in "Determine version" | medium | mitigate | Written only after validation (no newline possible); the error message never echoes the rejected value, so no workflow command can be smuggled into the log |
| T-01-08 | Spoofing | Ad hoc signature of source builds (project without team, install.sh overrides) | low | accept | Ad hoc signing is the project's chosen model (Developer ID rejected by the user, PROJECT.md Out of Scope); install.sh still runs `codesign --verify --deep --strict` before and after installing |
| T-01-SC | Tampering | Actions used by release.yml | high | mitigate | Only GitHub-owned `actions/checkout@v7` and the local `select-xcode` composite; no third-party action and no package-manager install in the release job |
