- URL commands today: `URLCommands.register(appState:)` (called from `AppDelegate.applicationWillFinishLaunching`) installs an Apple Event handler for GetURL on a private `Handler: NSObject` with an `@objc` method that wraps the call in `MainActor.assumeIsolated`. `URLCommands.perform(_:appState:)` checks the scheme `holzbar` and the host, reads arguments from `pathComponents` (dropping "/", percent-decoded), lower-cases only the section argument (profile names keep their case), and switches over toggle, show, hide, search, settings, shelf / ice-bar, auto-rehide, application-menus, profile. Its two log lines (full URL, public) are SEC-02's (Phase 5); leave them as they are here. The Info.plist declares only the `holzbar` scheme.
- SwiftUI routes an external URL to a scene unless the app delegate handles it; per Apple's `handlesExternalEvents(matching:)` documentation, without a matching scene it opens a new instance of the first scene without the modifier, and an empty set never matches. holzBar's scenes are `SettingsWindow` and `PermissionsWindow`, both built by `HolzBarWindow` (`Window(id.titleKey, id: id.rawValue)`, `.defaultLaunchBehavior(.suppressed)` on macOS 15+, a legacy variant on 14). `AppDelegate` is `@MainActor` and already owns `appState` (created in `init`).
- Windows today: `AppState.openWindow(_:)` / `dismissWindow(_:)` dispatch to the main queue ("prevents conflicts with SwiftUI") and call `EnvironmentValues().openWindow(id:)` / `.dismissWindow(id:)`. `HolzBarWindow` already reads `@Environment(\.openWindow)` and `@Environment(\.dismissWindow)` at scene level and calls both once in `.once { }` (the trick that creates the NSWindow early). `SettingsWindow` and `PermissionsWindow` (`@ObservedObject var appState`) construct `HolzBarWindow(id:)`. Callers of the AppState methods: `AppDelegate`, `URLCommands`, `PermissionsView`, `MenuBarSearchPanel`, `HolzBarShelf`, `AppState.performSetup`.
- Deep link: `ScreenRecordingPermission` in `holzBar/Permissions/Permission.swift` uses the pre-Ventura pane id; the current one is `x-apple.systempreferences:com.apple.settings.PrivacySecurity.extension?Privacy_ScreenCapture` (macOS 13+).
- AXSwift is imported only by `Shared/Utilities/AXHelpers.swift` and `Shared/Services/SourcePIDCache.swift` (both compiled into the app and the XPC service). Its types used: `UIElement`, `Application`, `Role`; functions: `checkIsProcessTrusted(prompt:)`, `systemWideElement.elementAtPosition`, `Application(runningApp)`, `attribute(.extrasMenuBar | .enabled | .frame | .menuBar)`, `arrayAttribute(.children)`, `role()`.
