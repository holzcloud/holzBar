# Phase 06.1: Compatibility check Summary

holzBar's deployment target stays macOS 14. CI now proves it: the `compat` job in `.github/workflows/build.yml` takes the app the build job made (Xcode 27.0, Swift 6.4.0) and launches it on the `macos-14`, `macos-15`, `macos-26` and `xcode-27` (macOS 27) runners. holzBar must still be running after 20 s; otherwise the job prints the output, the crash report and the log and fails. On macOS 14, 15 and 26 it then runs `swift test` with the runner's newest Xcode and the pinned Swift toolchain. The `xcode-27` leg was added in Phase 7, so the README can say "launched on macOS 14, 15, 26 and 27"; it skips the tests, which the test job runs on the same image.

## What the check found

| Runner | macOS | Launch | Unit tests |
|---|---|---|---|
| macos-14 | 14.8.9 | still running after 20 s (after the fix) | 371 passed |
| macos-15 | 15.7.9 | still running after 20 s | 371 passed |
| macos-26 | 26.6.2 | still running after 20 s | 371 passed |
| xcode-27 | 27.0 | added in Phase 7, first run with the next push | 371 passed (test job) |

Figures from CI run 37117883138 (the green run of #42). The binary's minimum macOS (`vtool`, `minos`) is 14.0.

- **macOS 14 launch crash.** holzBar aborted at launch with a fatal exclusive access conflict: a scene's once action called `openWindow` while SwiftUI was still updating the scene. The window scenes now open after the scene update. The crash came in with API-08 (Phase 4) and never shipped: 0.0.5 still opened windows through `EnvironmentValues()`.
- **Tests on the macOS 14 runner** did not compile with Xcode 16.2's macOS 15.2 SDK, which does not mark `mach_task_self_` as concurrency-safe; the tests read the task port another way.
- **select-xcode** accepts Xcode's short version name (`Xcode_26.3.0.app` reports "Xcode 26.3").

## Decision

The user keeps macOS 14 and later (COMPAT-02). The cost is one CI matrix and the pre-26 backend (`WindowListBackend`), which already existed; dropping 14 and 15 would remove no feature and the check already caught a real crash.

## COMPAT-03

README badge "macOS 14 → 27", the comparison table ("macOS 14 – 26" and a row for the CI launch check), the build-from-source section, the cask (`depends_on macos: :sonoma`) and the 0.0.6-beta1 release notes all say macOS 14 to 27.
