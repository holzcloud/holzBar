# Phase 05.1.1.1.1 Plan 01: Apple APIs and toolchain Summary

Xcode 27.0 (macOS 27 SDK) with Swift 6.4.0 on CI and for releases, `swift test` under the app's own concurrency settings, `@concurrent` instead of awaited detached tasks, no to-be-deprecated URL API, and a small HIG pass (adaptive colours, button order, destructive marking, VoiceOver) — draft PR #41, CI green.

## What was done

**APPLE-01 (Swift 6.4).** Read swift.org's 6.4 and 6.3 release posts. Real gains for holzBar:
- `Package.swift` (tools 6.0 → 6.2): every target gets `NonisolatedNonsendingByDefault`, `InferIsolatedConformances` (= `SWIFT_APPROACHABLE_CONCURRENCY`) and `MemberImportVisibility`; `HolzBarCore` and `HolzBarMacOS27Core` get `.defaultIsolation(MainActor.self)` (= the app target's `SWIFT_DEFAULT_ACTOR_ISOLATION`). Before, `swift test` compiled the same files with none of these. Verified on Linux beforehand (swift:6.4 container, stub CoreGraphics/os/Darwin modules, SIL diagnostics) and on CI: 338 tests (6 + 127 + 205) pass on the macOS 27 runner.
- `@concurrent` replaces `await Task.detached { … }.value` in `ItemIconStore.storeImage` (image scaling) and the detached task inside `MenuBarItemEventPoster.getCurrentBounds`.
- Not adopted (no real gain or needs macOS 27): module selectors, async `defer`, `withTaskCancellationShield`, `@diagnose`, Observable fine-grained notifications, Span/InlineArray additions, `some P?` spelling.
- README already said "Built with Swift 6.4"; the selling point now also names Xcode 27 and the concurrency model.

**APPLE-02 (deprecated API).**
- Compiler: with Xcode 26.6 and with Xcode 27.0 the only deprecation warning is `ScreenCapture.swift:86` `CGImage(windowListFromArrayScreenBounds:…)` — kept, the documented exception; its comment now says why (ScreenCaptureKit captures only on-screen content; hidden items sit off screen). The macOS 27 SDK added no new deprecation warning.
- To-be-deprecated (no warning, `deprecated: 100000`): `URL(fileURLWithPath:)`, `appendingPathComponent(_:)`, `URL.path` → `URL(filePath:directoryHint:)`, `appending(path:)`, `path(percentEncoded: false)`, `URL.homeDirectory` in `SettingsSyncLocation`, `WallpaperChangeMonitor` and two test files. Old and new results compared on Linux for spaces, Unicode, `%20`, trailing and double slashes, relative and `..` paths: identical.
- Grep found none of: `activate(ignoringOtherApps:)`, `lockFocus`, `launchApplication`, `CGDisplayCreateImage`, `kUTType`, `NSUserNotification`, `onChange(of:perform:)`, `.foregroundColor`, `.cornerRadius`, `NavigationView`, `edgesIgnoringSafeArea`, `synchronize()`, `Process.launch()`/`launchPath`, `allowedFileTypes`, `ObservableObject`/`@Published`, Combine, `Text + Text`, `tabItem`, `presentationMode`.

**APPLE-03 (Xcode 27).** `actions/runner-images` lists an `xcode-27` / `xcode-27-xlarge` image (public preview, #14404, macOS 27.0) with Xcode 27.0 (default, 27A266a), 27.1 (`Xcode_27.1_beta.app`) and 27.2 beta, macOS 27.0/27.2 SDKs. select-xcode now defaults to 27.0; build, test and release jobs run on `xcode-27` (cask job stays on `macos-26`). First CI run on the 27 SDK found one error, fixed (see deviations). README "Build from source" names Xcode 27.

**APPLE-04 (HIG).** Permissions window: privacy lines in `.tint` instead of fixed light blue (contrast in light mode), Continue is `.defaultAction`, app icon and bullets hidden from VoiceOver. URL-command question: Apply right, Cancel left, Escape cancels via Cancel's key equivalent in every language, no Return default, the Escape event monitor removed. Settings import: "Import and Restart" `hasDestructiveAction`, Cancel answers Escape. Spacing reset button: accessibility label. No new strings (strings-check: 359 strings in 5 languages).
