# Phase 05.1.1.1 Plan 03: item images and coloured folders, borders and tints, settings sync through any folder, five languages Summary

Any menu bar item can carry an image of your choice or its app's icon, and app icons stand in wherever Screen Recording is missing; groups get a colour and an image; borders can be dashed or dotted and the tint can follow the wallpaper, the accent colour or the system's glass; settings sync works through any folder the Macs sync; and holzBar speaks English, German, French, Italian and Romansh, with a CI job that proves every text is translated.

## What was done

### Task 1: item images and coloured folders (THAW-16) — 5d34de5
- `ItemIconChoice` and `HexColor` (Core, tested).
- `ItemIconStore`: choose an image (open panel), store it as a scaled PNG, use the app icon, reset; `image(for:captured:)` gives the chosen image, then the capture, then the app icon. Used by the Shelf, the search, the Layout pane, the hints and groups.
- Layout item context menu: "Choose Image…", "Use App Icon", "Reset Image".
- Groups: colour (`colorHex`), image file, "Choose Image…" and "Use Symbol"; the status item draws them.
- Defaults key `ItemIcons` (dictionary, settings kind declared).

### Task 2: borders and tints (THAW-17) — 74cfc48
- `BorderPattern` (Core, tested): solid, dashed, dotted dash patterns scaled to the border width.
- `WallpaperPalette` (Core, tested, adapted from Thaw, NOTICE): colours from the desktop picture strip; `DesktopPicture.palette(for:height:)`.
- `MenuBarTintKind` gains adaptive (wallpaper) and system glass (`NSGlassEffectView`, macOS 26 and later) with a tolerant decoder; "Use Accent Color" follows `NSColor.systemColorsDidChangeNotification`.
- Editor: border style picker, accent colour toggle; widths shown verbatim.

### Task 4 (user decision): settings sync through any folder (SYNC-01) — df6e9c4
- `SettingsSyncLocation` (Core, tested): bookmark resolution decisions, sync file path, display name.
- `SettingsSync`: folder bookmark (`SettingsSyncFolderBookmark`), stale bookmarks stored again, iCloud Drive users migrated without a prompt; `NSFilePresenter` plus a nonisolated `DispatchSource` folder watcher; no polling, no network code.
- Advanced pane: "Turn On…", "Change…", "Turn Off", "Through <folder>".

### Task 3: five languages (ICE-05), README — 37ae807
- `Localizable.xcstrings` (352 strings), `InfoPlist.xcstrings` (2: the copyright translated, the display name not), `AppShortcuts.xcstrings` (5 phrases, each with `${applicationName}`); 359 strings in total, each with German, French, Italian and Romansh.
- AppKit texts (menus, alerts, tooltips, panels, errors, permissions) go through `String(localized:)`; SwiftUI keys use interpolation instead of concatenation; plain Core texts are looked up with `String.localizedFromCatalog`.
- `knownRegions`: en, Base, de, fr, it, rm. No in-app language switcher: macOS's per-app language chooses it (README).
- `.github/scripts/strings-check.py` and the `strings` job in `build.yml`: every catalog parses with English as its source, every entry has four finished translations with the same format specifiers, and every literal in a localisable position of the code has an entry.
- README: "Five languages" selling point; rows below; feature entries for groups with colour and image, item images and the app-icon fallback, borders and tints, sync through any folder, languages; permissions table "A folder you choose"; Screen Recording row names the app-icon fallback.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Folder watcher closure isolation**
- **Found during:** Task 4
- **Issue:** A handler closure formed in a main-actor context and run by a dispatch source off the main thread would trap at runtime.
- **Fix:** `SettingsSyncFolderWatcher` is a `nonisolated` class whose handler only calls the `@Sendable` callback.
- **Commit:** df6e9c4

**2. [Rule 2] Personal data in a log**
- **Found during:** Task 3
- **Issue:** `SettingsBackup.show` logged its message publicly; with localization the message can carry a file name.
- **Fix:** The message is logged `.private`.
- **Commit:** 37ae807

**3. [Rule 1 - Bug] Texts built by concatenation**
- **Found during:** Task 3
- **Issue:** "Show/Hide <section> Section", "Click/Show Item", "<n> second(s)" and "Below <n> %" were assembled from pieces no translation can reorder.
- **Fix:** Whole sentences per case, interpolated keys, a formatted percentage.
- **Commit:** 37ae807

**4. Positional format specifiers**
- The strings check compares the kinds of format specifiers, so translations may use `%1$@`/`%2$@` to reorder them.

**5. Extra task**
- SYNC-01 was added to this plan by the user's decision; the plan had 3 tasks, 4 were done.
