Facts gathered while planning (2026-10-02). Do not re-derive them:
- Homebrew's rename docs (docs.brew.sh/Rename-A-Formula): renamed casks are listed in the tap's `cask_renames.json` (`{"old": "new"}`, canonical names without a tap prefix, at the tap's root, which is this repository's root); "Homebrew uses the rename mapping during updates and `brew migrate`, so the target must exist in the same tap". Users who tapped `holzcloud/holzice` keep that tap (the same repository, reached through GitHub's redirect after the rename), so the mapping moves them to `holzbar` inside it. A `tap_migrations.json` is not needed (D-07: only if needed): both tap names point at this one repository, and a migration from one to the other would point the repository at itself.
- No `conflicts_with cask: "holzice"` (REN-07 lists it; this is a deliberate, evidence-based deviation to report in the SUMMARY): Homebrew's `Cask::Installer#check_conflicts` loads each conflicting token with `CaskLoader.load`, which follows `cask_renames.json`, so "holzice" would resolve to holzbar itself, and an installed holzbar would conflict with itself on every `brew upgrade`. The migrator also leaves `Caskroom/holzice` as a symlink to `Caskroom/holzbar`. The rename already guarantees both are never installed together, and the app's ConflictingApps (01.1-04) covers a holzIce installed by hand. A comment in the cask says so.
- `brew migrate` (`Cask::Migrator`): when the new cask is not installed it copies `Caskroom/holzice` to `Caskroom/holzbar`, rewrites the installed caskfile's token, and turns the old directory into a symlink. The installed caskfile is the old one (app `holzIce.app`, `uninstall quit: com.holzcloud.holzIce`), so the next upgrade removes holzIce.app and installs holzBar.app.
- `brew trust` stores trust per tap, formula, cask or command (`trust.json`). Whether trusting `holzcloud/holzice/holzice` carries over to `holzcloud/holzice/holzbar` after the rename is not documented; the cask workflow below measures it and README follows the measurement.
- USER DECISION (2026-10-02, overrides the rest of this plan where they differ): until the first holzBar release the cask keeps pointing at the existing holzIce 0.0.5 download, so `brew install --cask holzbar` works in the meantime.
