## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] brew update does not migrate when only holzice is trusted**
- **Found during:** Task 1 (first cask run on c814626)
- **Issue:** The plan expected `brew update` to migrate and measured trust only at `brew upgrade`. Homebrew loads the renamed cask (holzbar) only from a trusted source; `Caskroom.casks` falls back to the installed caskfile on `UntrustedTapError`, so the migration is skipped silently and `brew upgrade --cask holzbar` would fail with "not installed".
- **Fix:** The job now runs twice. Run 1 measures `brew update` with only the old trust (`==> trust carried over: no`), then covers the fix-up (`brew trust --cask holzcloud/holzice/holzbar`, `brew migrate --cask holzice`). Run 2 is the README path: trust holzbar, `brew update` (`==> migrated: yes`), upgrade, style, audit, uninstall. No assertion was weakened.
- **Files modified:** .github/workflows/cask.yml
- **Commit:** c3a30b7

**2. [Rule 1 - Bug] brew style rejected the cask desc**
- **Found during:** Task 1 (second cask run)
- **Issue:** `Cask/Desc: Description shouldn't contain the platform.` for "Menu bar manager (fork of Ice with macOS 27 support)".
- **Fix:** `desc "Menu bar manager forked from Ice"`.
- **Commit:** 50468c2

**3. [Rule 3 - Blocking] release.yml named the former app**
- **Found during:** Task 2 (repository-wide holzIce gate)
- **Issue:** The user decision's release sed matched `holzIce.app` literally, and the gate allows the former name only in the documented migration files.
- **Fix:** The postflight path and `writable_paths` are matched by pattern (`[^"/]*[.]app`); the comment says "the app under its former name". Retested locally.
- **Commit:** 2862a49

**4. [Rule 3 - Blocking] README gallery out of step with main**
- **Found during:** Task 2
- **Issue:** `main` gained #32 after 2b1b4f8, which drops the Search screenshot of the original Ice. Keeping it here would have conflicted on merge.
- **Fix:** The same four lines are dropped; the gallery caption ("taken when holzBar was called holzIce") sits under the Gallery heading. `git merge-tree` with `origin/main` reports no conflict.
- **Commit:** d6f029d

### Deviations from REN-07's text (by plan)

- **No `conflicts_with cask: "holzice"`:** `Cask::Installer#check_conflicts` loads the token through `CaskLoader`, which follows `cask_renames.json`, so holzbar would conflict with itself. The rename keeps both from being installed together, and the app offers to quit a running holzIce.
- **No `tap_migrations.json`:** both tap names point at this repository.
