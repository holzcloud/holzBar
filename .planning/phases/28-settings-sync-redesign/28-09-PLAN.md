<objective>
Add the macOS 27 families to the engine: the arrangement as `l27/<bundleID>` with explicit values, layout profiles as `prof/<profileID>`, and `KnownApplications27` as a union set, all authored and applied only on macOS 27 and relayed untouched on macOS 26. Capture of their changes is by intent events, never by diffing the defaults, because holzBar's own automatic stores write the same keys.

Purpose: D-04, D-05 and D-06 on the engine side, with the oracles of A2 §5.3 (INV-L1 to INV-L6) restricted to the 27 families and registered in the simulator. The app wires the user paths to these intents in plan 28-16.
Output: `SyncLayout27.swift`, small additions to the engine, Core tests, the simulator's layout events and the layout oracles.
</objective>
