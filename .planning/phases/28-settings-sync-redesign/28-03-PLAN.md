<objective>
Give layout profiles a stable ID, key profile hotkeys by that ID, stop the hotkey model from writing its setting back at load, split profile saving by macOS generation, and make every profile application say whether the user did it. Add the app type-check script every later plan uses.

Purpose: These are companion fixes of analysis §4.9 (items 1 and 5) and the profile identity of D-05: the `prof/<profileID>` sync family and capture rules (plans 28-09 and 28-16) need stable IDs, a byUser flag and load paths that never write synced keys. No sync behaviour changes in this plan; sync stays paused (D-12).
Output: `ProfileIdentity` in Core with tests, profile and hotkey changes in the app, `Scripts/typecheck-app.sh`.
</objective>
