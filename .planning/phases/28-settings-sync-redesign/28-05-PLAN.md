<objective>
Remove every load-time writer of a synced setting, remove the paused layout-edit hook of the old sync code, and repair the β1 seeded-flag artifact on macOS 26.

Purpose: Capture by normalized diff (plan 28-07) counts any change of a synced value as the user's. Analysis §4.9 lists these app writers as preconditions: a load that rewrites a value would mint a false user change on version skew (INV-A5). No sync behaviour changes here; sync stays paused (D-12).
Output: Four models that load without saving, the removed hook, a Core predicate with tests and the one-time repair.
</objective>
