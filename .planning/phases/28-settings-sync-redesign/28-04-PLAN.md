<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sync folder values → defaults writes | Values from other Macs become this Mac's preferences only through `defaultsWrites` |
| hardware identity → stored hash | The hardware UUID and uid must never leave the Mac |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-10 | Tampering | SyncProjection.defaultsWrites | high | mitigate | Per-value validation (kinds, number rules, l27 range 0 to 2, profile field types and lengths, hotkey decode); invalid units are skipped and reported, never written; local keys are never written because they have no synced class |
| T-28-11 | Information disclosure | SettingsSyncDevice hash | medium | mitigate | Salted SHA-256 including the uid, stored only in local SettingsSync… preferences (excluded from export, import and sync by prefix); never part of any device file field |
| T-28-12 | Spoofing | SyncIdentity collision signals | medium | mitigate | A file under this Mac's ID with other bytes for an own dot, another nonce or a conflict copy leads to re-identification that keeps the replica; nothing is dropped |
| T-28-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager install in this plan |
</threat_model>
