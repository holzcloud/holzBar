<objective>
Wire the user paths of the macOS 27 arrangement and of layout profiles to the engine's intents, keep holzBar's own automatic stores from overwriting intent, and re-check in code whether macOS 27 offers any other way for a user to arrange the bar.

Purpose: D-04 and D-05 on the app side, and SYNC-R06 and SYNC-R07. Plan 28-09 made the engine take only intents for these families; this plan makes the app send them at exactly the user's actions. It follows gate G1 and the host of plan 28-15.
Output: Capture at the Layout pane, the profile code and Import; protected placement and seeding with a tested pure rule; the recorded D-04 result; a lint that names any new arrangement writer.
</objective>
