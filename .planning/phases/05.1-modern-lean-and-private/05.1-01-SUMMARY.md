## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical] Log scanner instead of regex only**
- **Found during:** Task 1
- **Issue:** The plan's regex and a literal-only denylist missed `logger.log(...)` calls (item moves and clicks), interpolations containing a string literal (`app.localizedName ?? "An app"`) and bare `tag` interpolations, which all logged personal data publicly.
- **Fix:** `privacy-check.py logs` parses each Logger literal (single, triple and raw strings, nested parentheses and strings) for both rules, keeps the plan's regex as a second pass, adds `log` to the levels and `tags?` / `excluded` to the denylist. Also made private by hand: profile names (`LayoutProfiles` 89/104), the macOS 27 layout summary (`Concealer27` "Took the macOS 27 layout").
- **Commit:** `02b58bb`

**2. [Rule 1 - Bug] Group panel images never refreshed**
- **Found during:** Task 2
- **Issue:** `updateCache(sections:)` returned early unless the Shelf, search or the layout pane was shown, so the group popover's own update did nothing.
- **Fix:** The guard includes `isItemGroupPanelPresented`, which `MenuBarItemGroups` sets at once on show and from `NSPopover` notifications.
- **Commit:** `b36848c`

**3. [Rule 1 - Bug] Data race on the UUID cache**
- **Found during:** Task 2
- **Issue:** Pruning `uuidCache` from the manager while namespaces are created elsewhere would race on a plain static dictionary.
- **Fix:** The cache is a file-level `OSAllocatedUnfairLock`; `pruneUUIDCache(keeping:)` takes the window list of every space (`Bridging.getMenuBarWindowList(option: .itemsOnly)`), so windows on other spaces keep their UUID.
- **Commit:** `b36848c`

**4. [Rule 2 - Missing critical] Drag state and offline baseline**
- **Found during:** Task 3
- **Issue:** Stopping the drag monitors mid-drag would leave `isDraggingMenuBarItem` stuck; a fresh `NWPathMonitor` started while offline would fire the offline rule on enabling it, which the always-running monitor never did.
- **Fix:** `updateMonitors()` clears the drag flag when the mouse-up monitor stops; `startNetworkMonitor(recordsBaseline:)` records the first update without firing (except at launch, as before).
- **Commit:** `acf9586`

**5. [Rule 1 - Bug] CI: SwiftLint for_where and a throwing Task value**
- **Found during:** Task 3 (first CI run)
- **Issue:** `ItemChangeObserver27` had an `if` inside a `for` (for_where, strict); `AsyncLockTests` awaited the value of a Task whose `catch is CancellationError` was not exhaustive, so the value needed `try`.
- **Fix:** `filter` over the notifications; the task catches every error.
- **Commit:** `b1de5b6`
