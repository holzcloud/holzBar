# Phase 05.1 Analysis: modern, lean and private (LEAN-01)

**Analysed:** 2026-10-02, branch state after Phase 5 (27,168 lines of Swift in `holzBar/`, `Shared/`, `MenuBarItemService/`).
**Scope:** what is still left after Phases 1–5. Already done and not repeated here: pinned Xcode 26.6 and SwiftLint, AXSwift and Ifrit removed, modern URL/UserDefaults/CFPreferences/window/AX APIs, validated settings import, item images in Caches, one hover task, reveal rules on IOKit/NWPathMonitor, permission checks that stop once granted.

Effort: **S** < half a day, **M** 1–2 days, **L** several days. Line numbers are from this state of `main`.
The user picks; "do / skip" is a recommendation.

### 3.3 Proposed CI check "no network code" (PRIV-01)

Two layers in `.github/workflows/build.yml`:

1. **Source job `no-network`** (ubuntu, like `former-name`): `git grep -n -E` over `holzBar/ Shared/ MenuBarItemService/ Package.swift` for
   `URLSession|NSURLSession|URLRequest|NSURLConnection|NWConnection|NWListener|NWBrowser|NWEndpoint|NWProtocol|nw_connection|WKWebView|import WebKit|SFSafariViewController|CFSocket|CFStream(Create|Pair)|SCNetworkReachability|getaddrinfo|\bsocket\(|\bconnect\(|AsyncImage|import Network`
   with an allowlist file `.github/network-allowlist.txt` (`holzBar/MenuBar/RevealRules/RevealRules.swift: import Network`, `NWPathMonitor`). Any other hit fails with `::error::`. Also fails if a new Swift package appears in `Package.resolved` that is not in `.github/allowed-packages.txt`.
2. **Binary step after the build** (macOS job): `otool -L holzBar.app/Contents/MacOS/holzBar` must not link `WebKit` or `CFNetwork` directly (Foundation pulls CFNetwork in; check `nm -u` instead) — `nm -um` of both executables must not contain `_nw_connection_`, `_OBJC_CLASS_$_NSURLSession`, `_OBJC_CLASS_$_WKWebView`, `_socket`, `_connect`; `codesign -d --entitlements - holzBar.app` must not contain `com.apple.security.network`.

Effort S, risk low (false positives handled by the allowlist). **Do**; README "Principles" points to the job.
