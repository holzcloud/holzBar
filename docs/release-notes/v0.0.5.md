## holzIce 0.0.5 — beta

### 🛠 Fixed
- **The whole Mac could stop responding to clicks on first launch** while the original Ice was still running. Both apps tried to manage the same menu bar items: Ice kept moving holzIce's section dividers, hiding the pointer and posting mouse events in a loop, until nothing could be clicked. holzIce now checks for other menu bar managers (Ice, Bartender, Hidden Bar, Thaw) when it starts and offers to quit them before it continues.

### ⚠️ Known issues
- On macOS 27, items can't be reordered on the bar itself, only assigned to sections.
- The app is signed ad hoc; after an update macOS may ask for Accessibility again — use **Reset and Grant Again**.

### 📦 Install or update
Quit the original Ice first if it is running.
```sh
brew tap holzcloud/holzice https://github.com/holzcloud/holzIce
brew trust --cask holzcloud/holzice/holzice
brew install --cask holzice      # first install
brew upgrade --cask holzice      # update
```

If macOS says holzIce can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzIce.app
```

If the Mac ever stops responding to clicks while holzIce runs, press **⌘ Option Esc**, select holzIce and click **Force Quit** — no restart needed.
