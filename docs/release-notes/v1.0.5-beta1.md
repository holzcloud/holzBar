## holzBar 1.0.5 beta 1

### ✨ New
- **Command-drag across the holzBar icon:** on macOS 27, dragging an item with ⌘ Command across the holzBar icon hides its app (to the left) or shows it (to the right), with Undo in Menu Bar Layout.

### 🐛 Fixed
- **Automation rules:** on macOS 27, a rule that moves one app no longer makes your other hidden apps visible, and applying a profile keeps the apps a rule hides hidden.
- **Visible apps:** on macOS 27, an app you made visible is no longer hidden again as a new item.
- **Always-hidden section:** on macOS 27, turning it off moves its apps to Hidden, where the Shelf and the holzBar icon reach them.
- **Show on hover:** a section you opened with a click, a hotkey or the Shelf no longer hides when the pointer leaves the menu bar, and nothing hides while an item's menu is open.
- **Automatic rehide:** waits while an item's menu is open or the pointer is on the Shelf, and also closes the hidden section that showing the always-hidden one opened.
- **⌘ Command-drag:** no longer shows hidden items while the Touch ID lock, Zen mode or Collapse is on, and hides them again after the drop.
- **Quick peek and changed items:** the peek hotkey hides again after Touch ID, and an item shown because it changed stays while its menu is open or after you opened its section.
- **holzBar icon:** an icon dragged into the hidden section moves back out of it on its own.
- **macOS 27:** hiding comes back after MenuBarAgent restarts, helper apps and apps that start slowly appear sooner, busy apps such as Slack cost less energy, and items folded beside the notch come back on a wider display at once.
- **Touch ID:** after you unlock the hidden items, the app you were using keeps the keyboard focus.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 1.0.0, so updating keeps the Accessibility and Screen Recording permissions.

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
