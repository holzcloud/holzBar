## holzBar 0.0.9 beta 1

The first beta of 0.0.9. It adds a command palette, an AppleScript dictionary, sound output and Bluetooth as rule conditions, moods (saved looks of the menu bar), grid and column layouts for the holzBar Shelf, and opt-in usage suggestions.

### ✨ Highlights
- **Command palette**: set a hotkey in **Settings → Hotkeys** and a Spotlight-like panel opens. Type to find an action, a layout profile, a mood, a rule or a menu bar item; Return runs it, Escape closes it. Starting with `>` leaves out the menu bar items. It keeps no history and needs no permission.
- **AppleScript dictionary**: show, hide and toggle a section, apply a profile, turn rules and Zen mode on or off, and read the profile and rule names. Commands take the same decision as `holzbar://` URL commands: lasting changes ask first. A script cannot create or change rules, profiles, scripts or settings.
- **Moods**: save the current look of the menu bar under a name, switch to it in one click, from the palette, or with a rule ("switch to a mood").
- **Usage suggestions** (off by default): after you turn it on, holzBar counts how often you open each item (per day, 30 days, in one file on this Mac). After 14 days it suggests hiding items you did not open for 14 days. **View Data** shows everything stored and **Forget Everything** deletes it.

### 🆕 New
- **Sound output and Bluetooth as rule conditions**: "the Mac plays sound through …" needs no permission. "A Bluetooth device is connected" asks macOS for the Bluetooth permission only when you add such a condition.
- **holzBar Shelf layouts**: a row, a grid or a column, and the Shelf fades in (never with Reduce Motion on). Up and down arrows move the highlight in a grid and a column.
- **Keep the Mac awake** from a hotkey and from the command palette.

### 🔧 Changed
- **An item that a rule controls and that you moved by hand goes back** at the next evaluation of its rule, instead of staying where you put it.

### ⚠️ Known issues
- Smooth show and hide covers only the holzBar Shelf; the bar itself does not animate yet.
- Replacement items for Apple's items and the new Settings window of the design system are not part of this beta.
- A rule cannot use Energy Mode: macOS has no public interface for it. Low Power Mode works as before.
- A manual move of a rule-controlled item is undone without a hint in the pane.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6, 0.0.7 and 0.0.8, so updating keeps the Accessibility and Screen Recording permissions.

holzBar runs on macOS 14 Sonoma and later, up to macOS 27. Only macOS 26 and 27 are tested.
