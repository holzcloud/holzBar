## holzBar 1.0.0 beta 2

### ✨ Highlights
- **Sorting on macOS 27:** Menu Bar Layout puts the items of a section in order.
- **The notch hub's tabs in one row** across both sides of the notch.
- **Clock, Control Center, Wi-Fi and battery** can stay hidden while the Shelf is on, and open from the Shelf.
- **Drop on the open Shelf:** a bar item dropped there hides its app on macOS 27.

### 🆕 New
- **Sort items in Menu Bar Layout (macOS 27):** drag an item to another place in its row, or use Option and the arrow keys or VoiceOver, then press **Apply**. holzBar drags the item for you, with the pointer hidden for a moment.
- **Drop on the open Shelf (macOS 27):** drag a bar item straight down onto the open Shelf to hide its app. The Shelf shows an accent outline while the item is over it.
- **Apple Items with the Shelf on:** the hidden clock, Control Center, Wi-Fi and battery get a symbol tile in the Shelf that opens the item.
- **Copy Diagnostics** has a **Last drop** line that says where the last drop landed.

### 🔧 Changed
- The hub's tabs stand in one row across both sides of the notch, with the status pills and the settings button at the far right. A More menu appears only where the row does not fit.

### ⚠️ Known issues
- Dropping an item on the holzBar icon may still not hide its app on macOS 27; Copy Diagnostics names the last drop.
- Sorting stops for the session if macOS does not take the drags; the sections still apply.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
