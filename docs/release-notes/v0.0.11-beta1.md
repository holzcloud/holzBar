## holzBar 0.0.11 beta 1

### 🆕 New
- **Smooth show and hide on macOS 26:** the menu bar items slide in and out. Switch it off under **Settings → General → Animate showing and hiding**. It never animates with Reduce Motion on.

### 🔧 Changed
- **Search and Hints panels** have the new glass look, with key caps for the hint letters.
- Type sizes and spacing in Settings come from one shared set of values; nothing should look different.

### ⚠️ Known issues
- On macOS 14, 15 and 27 the bar does not slide (macOS 27 animates it itself).
- The command palette still has its old look.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 0.0.10, so updating keeps the Accessibility and Screen Recording permissions.
