## holzBar 0.0.8 beta 2

The second beta of 0.0.8 "Automation". It finishes the release: the two old "show hidden items" settings are now rules of the automation engine, and a camera or the microphone in use can be a rule condition. **Like the first beta, the new features are Previews: built and unit tested, but not yet tested on a real Mac by the maintainer.** Each one carries a **Preview** badge in the app. Please try them and report what does not work on the [issue tracker](https://github.com/holzcloud/holzBar/issues). Everything else of [beta 1](v0.0.8-beta1.md) is unchanged.

### ✨ Highlights
- **Camera and microphone in use** as rule conditions (Preview), for example to turn Zen mode on during a call or show an item while the camera runs. holzBar only reads whether another app records or a camera is running, the same signal as the dot on its icon on macOS 27: no permission, no polling, no audio or video is opened. Needs macOS 14.2 or later; before that the conditions are never true.
- **"When the battery is low" and "When the network connection is lost" are rules now.** The first time this beta starts, holzBar turns the two settings that were on into two rules in the Automation pane, named like the old settings, and forgets the old setting. You can now change, combine or switch them off like any other rule (for example "on battery, below 15 %, and an external display is not connected").

### 🔧 Changed
- The two old settings are gone from **Settings → Advanced**; the **Show Hidden Items Automatically** section no longer exists.
- A low-battery rule now looks at "on battery" and "below the level" together. Before, plugging the charger in and out again while the level stayed low did not show the items again; now it does, because the rule ended while the charger was in.
- The **Preview** badge stands alone, without the explanation next to it; its tooltip says that the feature is not yet tested on a Mac.
- New texts exist in English, German, French, Italian and Romansh; the French, Italian and Romansh texts are machine-made and not yet checked by a native speaker.

### ⚠️ Known issues
- **Nothing in 0.0.8 was tested on a real Mac by the maintainer.** The Focus filter in particular depends on macOS calling it, which has been reported not to work on macOS 26.5.
- Rules cannot yet be exported with a script, by design; the other rules are exported and imported with your settings. A settings file from 0.0.7 that still contains the old settings is converted into rules the next time holzBar starts.
- A VPN is seen only when the traffic goes through a tunnel; a VPN that routes only some networks is not.
- On macOS 27 a rule that shows one item moves all items of its app.
- Widgets, the AppleScript dictionary, animations, profile hooks, more triggers (Bluetooth, audio, Energy Mode) and settings sync are planned for later releases.
- The other known issues of 0.0.7 still apply.

### 📦 Install
Update an installed holzBar (this is a beta; Homebrew installs the newest version of the cask):
```sh
brew update && brew upgrade --cask holzbar
```

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 and 0.0.7, so updating keeps the Accessibility and Screen Recording permissions.

holzBar runs on macOS 14 Sonoma and later, up to macOS 27. Only macOS 26 and 27 are tested.
