## holzBar 0.0.10

A stable bugfix release: holzBar no longer crashes when an app launches or quits. It changes nothing else; everything in the [0.0.9 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.9) still applies.

### 🐛 Fixed
- **Crash when an app launched or quit (macOS 26).** holzBar looks up which app owns each menu bar item on a background queue. That lookup read the list of running apps there, while macOS changes the same list on the main thread whenever an app launches or quits. When the two overlapped, the copy of the list was corrupt and holzBar was terminated with a segmentation fault, in different places of the same function. The list is now read on the main thread. holzBar 0.0.7 to 0.0.9 were affected; a stress test that starts and ends about 90 short-lived processes per second crashed the old read within a second and the new read not at all in runs of up to five minutes.
- **The same read on macOS 27** (the menu bar item provider) is moved to the main thread too. No crash of it has been reported.

### ⚠️ Known issues
- **Not tested on a Mac:** this fix is unit tested, type checked and stress tested outside the app, but the fixed holzBar itself has not been run yet. Please report a crash if you still see one, with the crash report from Console (Crash Reports) or `~/Library/Logs/DiagnosticReports`.
- The known issues of [0.0.9](https://github.com/holzcloud/holzBar/releases/tag/v0.0.9) still apply.

### 📦 Install
Update an installed holzBar:
```sh
brew update && brew upgrade --cask holzbar
```

If you installed the beta channel (`holzbar@beta`), switch to the stable one: `brew uninstall --cask holzbar@beta`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzcloud/holzbar/holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 0.0.9, so updating keeps the Accessibility and Screen Recording permissions. Coming from 0.0.5, follow "Install and update" in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

holzBar runs on macOS 14 Sonoma and later, up to macOS 27. Only macOS 26 and 27 are tested.
