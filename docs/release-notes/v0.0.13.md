## holzBar 0.0.13

### 🆕 New
- **Shelf:** type to find and press Return to open an item's menu; Always Hidden sits behind a "+N" fold; apps that are not running can show dimmed (a click launches them); drag tiles to reorder, to another section or up onto the menu bar.
- **Built-in items:** Focus, AirDrop, media controls, fast user switching, a timer and app launchers, added under **Settings → Modules → Widgets**.
- **Animation styles:** Instant, Smooth or Fade as picture cards in **Settings → General**.
- **Layout editor with Apply:** changes are a draft until you press **Apply**; a "New items" tile shows where new items land.
- **Per display:** each display can always show everything or collapse.
- **Menu bar icon styles:** chevron, arrow, eye, dots, grid, panel, dot, or no icon.
- **Search:** short names such as `bt` and `wifi`, and items you open often come first (**Forget** clears it).
- **Clock click:** opens Notification Center while items are hidden (macOS 27).
- **Six more languages:** Spanish, Portuguese (Brazil), Japanese, Simplified Chinese, Korean and Russian.

### 🔧 Changed
- Settings use picture cards for visual choices, with a calmer layout.

### 🐛 Fixed
- Picture cards in Settings no longer overlap or get clipped; they wrap when the pane is narrow.

### ⚠️ Known issues
- Focus, AirDrop and fast user switching items open Apple's own item or the matching System Settings pane and show no state.
- With six or fewer hidden items the Shelf Grid looks like the Row.
- On macOS 27 dragging a tile inside a section does nothing, because macOS orders the items there.
- Type to find in the Shelf works when the Shelf is opened by hotkey.

### 📦 Install
Update an installed holzBar:
```sh
brew update && brew upgrade --cask holzbar
```

If you installed the beta channel (`holzbar@beta`), switch to the stable one: `brew uninstall --cask holzbar@beta`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzcloud/holzbar/holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 0.0.12, so updating keeps the Accessibility and Screen Recording permissions. Coming from 0.0.5, follow "Install and update" in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
