## holzBar 0.0.7 beta 1

A fix for macOS 26. Everything new in 0.0.6 is described in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

### 🛠 Fixed
- **holzBar finds the menu bar items again on macOS 26.** In 0.0.6, **Settings → Menu Bar Layout** and the holzBar Shelf stayed on "Loading menu bar items…", and clicking the holzBar icon showed nothing. holzBar did not recognise its own section dividers: to learn which app an item belongs to, it asked a helper that in turn asked holzBar, and holzBar waited for that answer instead of giving it. The fallback meant for this never matched on macOS 26 either. holzBar now waits without blocking itself, and it recognises its own dividers by where their windows are, without asking anyone.
- **Less work on the main thread.** The signature check of holzBar's menu bar item helper no longer runs on the main thread.

### 📦 Install
Update an installed holzBar:
```sh
brew update && brew upgrade --cask holzbar
```

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6, so updating from 0.0.6 keeps the Accessibility and Screen Recording permissions. Coming from 0.0.5, follow "Install and update" in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
