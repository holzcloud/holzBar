## holzBar 1.1.0 beta 1

### ✨ New
- **Settings, redesigned:** eleven panes sorted by task, compact rows with their explanation one click away, and a search over every setting with ⌘F.
- **Layout as a list:** Layout shows your items as bars or as a list, with a filter and a section menu for each item.
- **Undo after every change:** after a change of the layout, in Settings or in the menu bar, a notice offers Undo, and ⌘Z works too.
- **A short introduction:** the first launch needs only Accessibility and then shows three short steps, which About shows again.
- **Move to:** the menu of an item in Layout starts with Move to Visible, Hidden or Always Hidden.
- **More in holzBar's menu:** holzBar's menu has Arrange Menu Bar… and Profiles, which applies a profile in one click.
- **Whole apps on macOS 27:** on macOS 27, Layout highlights the items of one app together and says that macOS hides whole apps.
- **Deleting can be undone:** a deleted condition, group, snapshot, mood or profile hook comes back with Undo.

### 🐛 Fixed
- **Tidy-up question:** no longer interrupts after the first launch; the suggestion waits in Layout.
- **Loading:** loading the menu bar items no longer spins without end, and empty lists say what to do.
- **First launch:** no longer lists Calendar and Bluetooth; their modules ask when you switch them on.
- **Usage suggestions:** turning them off asks before it deletes the stored usage.
- **Screen Recording:** the offer to use it appears in holzBar's own look.
- **Item pictures:** on macOS 27, an app whose picture matched another app's tile gets its own picture again, and items without a picture show their app's icon.
- **Wording:** holzBar uses one word for each thing: Always Hidden, apps, and Delete for what you made.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 1.0.0, so updating keeps the Accessibility and Screen Recording permissions.

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
