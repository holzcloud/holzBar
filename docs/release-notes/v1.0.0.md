## holzBar 1.0.0

### ✨ Highlights
- **Eight modules for the notch hub:** Now Playing, Calendar, Live activities, Timers, File drop, Display controls, Notifications and Accessory alerts. Each is off until you switch it on, under **Settings → Modules**.
- **Sorting on macOS 27:** Menu Bar Layout puts the items of a section in order.
- **Count badge** on the holzBar icon says how many items are hidden.
- **Twenty languages:** nine more, all machine-made.

### 🆕 New
- **Now Playing:** title, artist, album, progress and artwork of what Music and Spotify play, with play or pause, previous and next. **Read all apps** (off by default) also follows browsers and video apps.
- **Calendar:** your next events, with a **Join** button for meeting links. It asks for Calendar access when you switch it on.
- **Live activities:** a capsule below the notch while a camera or microphone is in use or a download is running in your Downloads folder.
- **Timers:** timers, countdowns to a moment and a stopwatch, with a sound when one ends.
- **File drop:** drag files to the notch, keep them in a stash and drag them out as copies.
- **Display controls:** a volume slider with mute and a brightness slider.
- **Notifications:** the banners and alerts macOS shows, newest first, with a list of apps to exclude.
- **Accessory alerts:** a capsule when AirPods or headphones connect or run low on battery. It asks for Bluetooth only when you switch it on.
- **Sort items in Menu Bar Layout (macOS 27):** drag an item to another place in its row, or use Option and the arrow keys or VoiceOver, then press **Apply**.
- **Drop on the open Shelf (macOS 27):** drag a bar item straight down onto the open Shelf to hide its app.
- **Apple Items with the Shelf on:** the hidden clock, Control Center, Wi-Fi and battery get a symbol tile in the Shelf that opens the item.
- **Copy Diagnostics** has a **Last drop** line that says where the last drop landed and a **Last Shelf click** line.
- **Count badge:** off until you switch it on under **Settings → General**.
- **Languages:** Dutch, Polish, Czech, Hungarian, Swedish, Turkish, Indonesian, Ukrainian and Traditional Chinese.

### 🔧 Changed
- The hub's tabs stand in one row across both sides of the notch. A More menu appears only where the row does not fit.
- holzBar now carries one signed library, `NowPlayingRemote.framework`, for Read all apps. There is still no XPC service or helper app.
- holzBar is signed with one entitlement, `com.apple.security.personal-information.calendars`, which only lets macOS ask for Calendar access.

### 🐛 Fixed
- Updating from macOS 26 to 27 keeps your hidden items hidden.
- A click on a Shelf tile that does not reach its item beeps and is announced to VoiceOver.
- Hidden items such as Time Machine and Docker no longer drop out of the Shelf when their app misses one read or reports no item while hidden.
- On macOS 27.2 the items macOS folds behind its overflow button stay listed in their section.
- The layout bars in Menu Bar Layout use a thin overlay scroller instead of the thick legacy track.

### ⚠️ Known issues
- Dropping an item on the holzBar icon may still not hide its app on macOS 27; Copy Diagnostics names the last drop.
- Sorting stops for the session if macOS does not take the drags; the sections still apply.
- Music's progress can drift after you skip inside a song, and the media keys go to the app macOS chooses.
- Read all apps may stop working after a macOS update; it then says so. Now Playing has no lyrics.
- Brightness and the accessory battery levels use macOS calls that Apple does not document and may stop working in a later macOS; each has a switch to turn it off.
- Notifications follows a structure macOS may change, sees only banners and alerts that appear on screen, and may show a bell instead of an app name.
- Live activities recognises downloads of Safari, Chrome, Edge, Brave, Firefox and Opera and shows no percentage.
- File drop takes files, folders and apps, not text, links or files another app only promises.
- A running timer moves with the Mac's clock if you change it.

### 📦 Install
Update an installed holzBar:
```sh
brew update && brew upgrade --cask holzbar
```

If you installed the beta channel (`holzbar@beta`), switch to the stable one: `brew uninstall --cask holzbar@beta`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzcloud/holzbar/holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 0.0.13, so updating keeps the Accessibility and Screen Recording permissions. Coming from 0.0.5, follow "Install and update" in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
