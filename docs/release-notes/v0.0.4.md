## holzIce 0.0.4 — beta

### ✨ New look
- **New logo and app icon** from the holzcloud family: an ice cube carrying the chevron, standing on the wooden plank.
- **New menu bar icon** to match: the ice cube with its chevron on a short plank. It stays the default ("holzIce" in Settings → General → holzIce icon), and your choice of icon is kept.

Everything else is the same as in [0.0.3](https://github.com/holzcloud/holzIce/releases/tag/v0.0.3).

### ⚠️ Known issues
- On macOS 27, items can't be reordered on the bar itself, only assigned to sections.
- The app is signed ad hoc; after an update macOS may ask for Accessibility again — use **Reset and Grant Again**.

### 📦 Install or update
```sh
brew tap holzcloud/holzice https://github.com/holzcloud/holzIce
brew trust --cask holzcloud/holzice/holzice
brew install --cask holzice      # first install
brew upgrade --cask holzice      # update
```

If macOS says holzIce can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzIce.app
```
