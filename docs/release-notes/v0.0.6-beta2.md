## holzBar 0.0.6 beta 2

A quick fix for 0.0.6 beta 1. Everything new in 0.0.6 is described in the [beta 1 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6-beta1).

### 🛠 Fixed
- **Turning on settings sync no longer crashes holzBar.** In beta 1, choosing a sync folder in **Settings → Advanced → Sync settings between your Macs** crashed holzBar, and because sync then stayed on, holzBar crashed at every launch after that. The sync folder is now watched on the queue macOS calls it on, as intended. If beta 1 crashed for you, update and holzBar starts again with sync on.

### 📦 Install
Update an installed holzBar:
```sh
brew update && brew upgrade --cask holzbar
```

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as beta 1, so updating from beta 1 keeps the Accessibility permission. Coming from 0.0.5, follow "Updating from 0.0.5" in the [beta 1 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6-beta1).

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
