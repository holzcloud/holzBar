## holzBar 1.0.4 beta 1

### ✨ Improved
- **Order:** on macOS 26 and earlier, items keep their order inside each section and go back to their place when they reappear.
- **URL commands:** while Zen mode is on, `holzbar://application-menus/toggle` is ignored, and a burst of commands from another app is limited.

### 🐛 Fixed
- **Display changes:** holzBar no longer moves items or records your layout while the menu bar is still settling after a display change.
- **Slow apps:** apps that start slowly, such as OneDrive, are placed once they have started.
- **Item names:** items with a second line or a live value in their title keep their place.
- **Moves:** if one of holzBar's own moves pushes the items next to it out of place, holzBar puts them back.
- **Pinned controls:** Control Center controls pinned to the menu bar show as fixed in Menu Bar Layout on macOS 27.
- **Windows apps:** tray icons of Windows apps run with Wine or CrossOver are no longer moved by holzBar on its own.
- **Settings import:** an imported settings file can no longer bring an unlimited number of layout profiles.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 1.0.0, so updating keeps the Accessibility and Screen Recording permissions.

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
