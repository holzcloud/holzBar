## holzBar 0.0.8 beta 4

The fourth beta of 0.0.8 "Automation". **Like the earlier betas, the new features are Previews: built and unit tested, but not yet tested on a real Mac by the maintainer.** Each one carries a **Preview** badge in the app. Please try them and report what does not work on the [issue tracker](https://github.com/holzcloud/holzBar/issues). Everything else of [beta 3](v0.0.8-beta3.md) is unchanged.

### ✨ Highlights
- **macOS 27's own overflow button** (Preview): while macOS shows its folded items expanded beside the notch, the holzBar Shelf no longer lists them a second time. Whenever holzBar is not sure, the Shelf lists them as before, so no item becomes unreachable. Copy Diagnostics names the state on macOS 27. No new permission.
- **Menu bar styles** (Preview): the shape kinds are now called Single and Paired, and **Sections** draws one shape per section the bar shows (macOS 14 to 26); a **shape of its own for the Apple logo** in the bar's tint, the accent colour, the wallpaper's colour or a colour you choose; **outlines** in the accent colour or a gradient; **vertical gradients**, one gradient per shape and the **tint strength**. Every default looks as in beta 3; no new permission.

### ⚠️ Known issues
- The expanded state of macOS 27's overflow button is recognised from the public description and the frames macOS reports, not yet measured on a Mac.
- holzBar conceals as before when you click the overflow control; whether that moves the expanded icons is being checked.
- Sections is not available on macOS 27, where macOS decides the order of the items; a Sections choice is drawn as Paired there.
- The menu bar styles are drawn from the positions macOS reports and have not yet been checked on a Mac.
- The other known issues of beta 3 still apply.

### 📦 Install
Update an installed holzBar (this is a beta; Homebrew installs the newest version of the cask):
```sh
brew update && brew upgrade --cask holzbar
```

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 and 0.0.7, so updating keeps the Accessibility and Screen Recording permissions.

holzBar runs on macOS 14 Sonoma and later, up to macOS 27. Only macOS 26 and 27 are tested.
