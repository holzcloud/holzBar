## holzBar 1.2.0 beta 2

### 🐛 Fixed
- **Time windows:** a rule with a time window switches on time on the days the clocks change.
- **Unreadable rules and groups:** if holzBar cannot read an automation rule or item group, the others are no longer lost.
- **Energy:** rules about the sound output or Bluetooth, timers started from hidden items, volume changes and bursts of notifications use less energy.
- **Menu bar look:** the menu bar look removes its layers when they are no longer needed, follows the wallpaper reliably and uses the dark picture of a dynamic wallpaper in dark mode.
- **Menu bar hidden by macOS:** Settings again notices when macOS hides the menu bar automatically.
- **Untitled items:** two untitled items of one app are told apart in the search, in group panels and in Settings.
- **Items shown for a moment:** an item shown for a moment returns to its section even when the menu bar could not be read just then.
- **Undo in Layout:** a move in Layout that fails no longer leaves an Undo entry.
- **Item pictures:** on macOS 27, an item whose stored picture is lost is photographed again.
- **Pressed items:** before macOS 27, a cancelled move or click no longer leaves an item pressed.
- **Hotkeys:** hotkeys keep working after a menu was open, even when one could not be registered at once.
- **Notifications in the notch:** notifications in the notch keep working after Notification Center restarts.
- **Read all apps:** Read all apps waits longer before each new start of a helper that keeps ending.
- **Downloads in the notch:** downloads in the notch keep following the Downloads folder after it was briefly missing.
- **Brightness:** brightness in Display controls no longer switches itself off when several displays wake up at once.
- **Network readouts:** network readouts also work on Macs with many virtual network interfaces.
- **Counts in Settings:** counts and sizes in Settings use the correct singular and plural forms.
- **Share Profile and notices:** Share Profile says when the file cannot be saved, and a new notice in Settings stays its full time.
- **Search panel:** the arrow keys and Return in other holzBar windows are no longer taken by the open search panel.
- **Settings export:** a settings export now includes which modules are on, so a restored backup switches them on again.
- **Read all apps helper:** Read all apps checks its helper before every start and loads nothing from outside the system.
- **Shortcuts and artwork:** Shortcuts actions follow Zen mode like holzbar:// commands, and Now Playing artwork is read only as JPEG or PNG.
- **Profile and settings files:** a profile file is read as carefully as a settings file, and a settings file can no longer turn off automatic Zen mode or the camera and microphone dot on the holzBar icon.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 1.0.0, so updating keeps the Accessibility and Screen Recording permissions.

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
