## holzBar 1.2.0 beta 1

### ✨ New
- **System readouts:** tiles for the CPU, memory, network, disk and battery, and for the GPU behind its own switch, with two-minute curves in the Notch hub.
- **Readout widgets:** Network Speed, Disk Activity, GPU Load and Thermal State widgets, and new formats for the CPU, memory and battery widgets.
- **System alerts:** the notch warns when the CPU, memory pressure, thermal state, free disk space or the Mac's battery crosses a limit you set, with optional system notifications.
- **Devices:** Accessory alerts lists your devices with their battery levels, and the Lowest Device Battery widget shows the lowest one.
- **Indicators:** the closed notch flashes the input source and the volume or brightness, and can replace macOS's own display.
- **Dock badges:** the unread counts of apps in your Dock as menu bar items, with groups.
- **Import from Thaw and Hidden Bar:** bring over their settings with a preview, a backup and Undo.
- **Making room on macOS 27:** a notice when macOS folds menu bar icons away or they do not fit beside the notch, with Move to Hidden as one Undo step, or Automatic.
- **Ask where a new app goes:** an optional question for each new menu bar app.
- **Not shown by macOS:** on macOS 27, Layout lists the apps macOS does not show, each with a link to the fix.
- **Readable menu bar:** a built-in mood that gives the menu bar an opaque background.
- **Spotlight button:** a widget that opens Spotlight.
- **Large Percent:** a Battery widget format with a larger percentage.
- **Restart Menu Bar and Pause holzBar:** on macOS 27, in holzBar's menu and the command palette.
- **Notch hub:** gestures, a pin, opening on the display with the pointer, a switch for the bounce, and the hotkey closes the hub too.
- **Display tab:** choose the sound output, dim a monitor without brightness control, and no DDC request for three seconds after a wake.
- **Notifications and calendar in the notch:** a count and a card with a +N queue, and meeting details with a countdown to the next meeting.
- **Dynamic Island:** the hub opens below Apple's island, and a setting overrides the detection.

### 🐛 Fixed
- **Reopening:** holzBar opens Settings only when you open it from the Dock, the Finder, Spotlight or Launchpad, not for Siri on macOS 27.
- **Live Activities:** on macOS 27.3, holzBar leaves the system's Live Activities on the bar and neither counts, moves nor lists them.
- **Clicks on system items:** on macOS 27, a click through holzBar never leaves the mouse button down, and the click handling no longer waits on a busy holzBar.
- **Apps that launch hidden:** on macOS 27, an app that launches into a hidden section keeps its full item until holzBar has read it, up to 45 seconds.
- **Menu bar restarts:** on macOS 27, after more than three MenuBarAgent restarts in ten minutes holzBar shows every item for 30 minutes instead of retrying in a loop.
- **Shelf on a second display:** before macOS 27, the Shelf takes the colours of the display it is on.
- **Item pictures:** on macOS 27, an item never shows another item's picture when two items claim the same place.
- **Sleep and displays:** holzBar takes its hiding anew after a wake, an unlock or a display change, and saves your sections only from a settled bar.
- **Automatic rehide:** thin windows at the screen edge no longer hold it back, and a click inside an open menu or popup no longer starts it.
- **Closed notch:** where the menu bar is a little taller than the notch, the closed notch is as tall as the menu bar and meets the hardware notch.

### ⚠️ Known issues
- Item spacing is not offered on macOS 27; Settings says so.
- The warning that items do not fit beside the notch is an estimate and can be early or late.
- Read GPU load and Read badge counts use macOS interfaces that Apple does not document; each has its own switch and switches itself off if macOS changes it.
- Software dimming is a dark layer on the screen, so it shows in screenshots.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 1.0.0, so updating keeps the Accessibility and Screen Recording permissions.

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
