## holzBar 1.0.2

### ✨ Improved
- **What's New window:** a tab for every major version and a sub tab for every minor version, shown only when there is a choice; the window is more compact.

### 🐛 Fixed
- **Permissions:** the window is smaller, so Quit and Continue stay on screen on small displays.
- **Notch hub:** clicking a tab of the Notch hub no longer opens the Shelf.
- **holzBar icon:** clicking it no longer opens another item's menu, such as Wi-Fi, instead of the Shelf.

### 📦 Install
Update an installed holzBar:
```sh
brew update && brew upgrade --cask holzbar
```

If you installed the beta channel (`holzbar@beta`), switch to the stable one: `brew uninstall --cask holzbar@beta`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzcloud/holzbar/holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 1.0.0, so updating keeps the Accessibility and Screen Recording permissions. Coming from 0.0.5, follow "Install and update" in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
