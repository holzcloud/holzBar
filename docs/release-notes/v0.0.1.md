## holzIce 0.0.1 — first beta

The first release of holzIce, a fork of [Ice](https://github.com/jordanbaird/Ice) by Jordan Baird that keeps it working on macOS 27.

### Highlights
- **macOS 27 support** — a new backend for the redesigned menu bar ([jordanbaird/Ice#995](https://github.com/jordanbaird/Ice/pull/995)): hiding, the holzIce Bar and the layout editor work again. Your old layout is carried over on first launch.
- **Homebrew** — install and update with `brew install --cask holzice`.
- **Your Ice settings come along** — layout, hotkeys and appearance are imported from Ice on first launch.

### Fixed
- Stuck on the permissions window although permissions were granted: use **Reset and Grant Again**.
- Show on scroll now works with a mouse wheel.
- A section divider dragged out of the menu bar comes back.
- "Hide application menus" works without the always-hidden section.
- Displays without a menu bar no longer act like one.

### Changed
- New name, logo, app icon and menu bar icon.
- Built-in updates (Sparkle) are turned off; holzIce updates through Homebrew.

### Known issues
- On macOS 27, items can't be reordered on the bar itself, only assigned to sections.
- The app is signed ad hoc; after an update macOS may ask for Accessibility again.

### Install
```sh
brew tap holzcloud/holzice https://github.com/holzcloud/holzIce
brew trust --cask holzcloud/holzice/holzice
brew install --cask holzice
```

If macOS says holzIce can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzIce.app
```
