## holzBar 0.0.8

The stable release of 0.0.8 "Automation": rules that change the menu bar by themselves, scripts, widgets, a history of your layout, a lock for hidden items, more menu bar styles and the cooperation with macOS 27's own overflow button. It is the first stable release since 0.0.7. **Most new features are a Preview: built and unit tested, but not yet tested on a real Mac by the maintainer.** Each of these features carries a **Preview** badge in the app (the Focus filter, which you set up in System Settings, and the accessibility changes are marked Preview in these notes only). Please report problems on the [issue tracker](https://github.com/holzcloud/holzBar/issues). Coming from 0.0.7, everything below is new; the notes of [beta 1](https://github.com/holzcloud/holzBar/releases/tag/v0.0.8-beta1), [beta 2](https://github.com/holzcloud/holzBar/releases/tag/v0.0.8-beta2) and [beta 3](https://github.com/holzcloud/holzBar/releases/tag/v0.0.8-beta3) have more detail.

### ✨ Highlights
- **macOS 27's own overflow button** (Preview): while macOS shows its folded items expanded beside the notch, the holzBar Shelf no longer lists them a second time. Whenever holzBar is not sure, the Shelf lists them as before, so no item becomes unreachable. Copy Diagnostics names the state on macOS 27. No new permission.
- **Menu bar styles** (Preview): the shape kinds are now called Single and Paired, and **Sections** draws one shape per section the bar shows (macOS 14 to 26); a **shape of its own for the Apple logo** in the bar's tint, the accent colour, the wallpaper's colour or a colour you choose; **outlines** in the accent colour or a gradient; **vertical gradients**, one gradient per shape and the **tint strength**. Every default looks as in beta 3; no new permission.

### 🛠 Fixed
- **Accessibility** (Preview): VoiceOver names the rule, condition, script, profile hook, snapshot and widget rows and reads When and Then, Profile Hooks and every sheet title as headings, the Edit buttons as collapsed or expanded and a rule's battery level in percent; Add Rule puts the cursor in the rule's name; Escape closes Tidy Up, Share Profile, Import Profile, Copy Diagnostics and the script confirmations; with Increase Contrast, Settings draws its groups opaque with stronger borders and text; with Reduce Motion, items in Menu Bar Layout no longer slide; the holzBar Shelf shows a focus ring on the item the arrow keys select; gradient colour stops can be chosen, moved and removed with the keyboard and VoiceOver; the search panel, group popovers and group symbols are read by name; the Preview badge is easier to read in light mode.

### ⚠️ Known issues
- The expanded state of macOS 27's overflow button is recognised from the public description and the frames macOS reports, not yet measured on a Mac.
- holzBar conceals as before when you click the overflow control; whether that moves the expanded icons is being checked.
- Sections is not available on macOS 27, where macOS decides the order of the items; a Sections choice is drawn as Paired there.
- The menu bar styles are drawn from the positions macOS reports and have not yet been checked on a Mac.
- The accessibility changes have not yet been checked with VoiceOver, Full Keyboard Access and Voice Control on a Mac; the [checklist](https://github.com/holzcloud/holzBar/blob/main/docs/accessibility-checklist.md) lists what to check.
- The other known issues of beta 3 still apply.

### 📦 Install
Update an installed holzBar:
```sh
brew update && brew upgrade --cask holzbar
```

On the beta channel, `brew update && brew upgrade --cask holzbar@beta` brings 0.0.8 as well.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzcloud/holzbar/holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6, 0.0.7 and the 0.0.8 betas, so updating keeps the Accessibility and Screen Recording permissions. Coming from 0.0.5, follow "Install and update" in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

holzBar runs on macOS 14 Sonoma and later, up to macOS 27. Only macOS 26 and 27 are tested.
