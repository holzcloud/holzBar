## holzBar 0.0.12 beta 1

### 🆕 New
- **Apple Items (macOS 27):** hide the clock, battery, Wi-Fi or Control Center, and add replacement icons that open an Apple item. Switch it on under **Settings → Modules**.
- **Notch hub:** a panel at the notch for optional modules, off by default (**Settings → Modules → Notch**). No module in it yet.
- **Floating Shelf:** the holzBar Shelf can be a bar of its own (**Settings → General → Style**), and **Location** now offers the screen edge.
- **Smart Categories:** category buttons in the search (System, Network, Media and more). Switch them off under **Settings → Menu Bar Layout**.

### 🔧 Changed
- **Command palette** has the new glass look.

### ⚠️ Known issues
- With Smart Categories on, Option with the arrow keys switches the category button and no longer jumps a word in the search field.

### 📦 Install
Update an installed holzBar (this is a beta; it is on the beta channel only):
```sh
brew update && brew upgrade --cask holzbar@beta
```

If you installed the stable `holzbar`, switch to the beta channel first: `brew uninstall --cask holzbar`, then use the commands below.

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar@beta
brew install --cask holzcloud/holzbar/holzbar@beta
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

This release is signed with the same certificate as 0.0.6 to 0.0.11, so updating keeps the Accessibility and Screen Recording permissions.
