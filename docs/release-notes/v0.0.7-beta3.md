## holzBar 0.0.7 beta 3

Settings sync is removed from the app, and the glass and the holzBar Shelf become opaque when you turn on Reduce Transparency or Increase Contrast. Everything from the audit is described in the [0.0.7 beta 2 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.7-beta2), and everything new in 0.0.6 in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

### ✨ Highlights
- **Settings sync is gone from holzBar.** It was paused in beta 2; this beta removes it. The sync controls and the hints about settings from another Mac no longer appear, and holzBar no longer reads, writes or watches a sync folder. A redesigned sync is planned for 1.0.0. **Export…** and **Import…** in **Settings → Advanced** stay, so you can still move your settings to another Mac.
- **System Glass and the holzBar Shelf follow Reduce Transparency and Increase Contrast.** With either turned on in System Settings, Accessibility, Display, they are drawn opaque with a visible border, and the change applies at once, without a restart.

### 🆕 New
- **An opaque bar and Shelf under Reduce Transparency or Increase Contrast.** With the **System Glass** tint (macOS 26 and later) the bar is drawn as an opaque fill in the window background colour, with a thin border along the edge of its shape, so the menu bar stays legible. The holzBar Shelf, on every macOS version it runs on, gets an opaque background with a visible border. A border you chose in **Settings → Appearance** stays as you set it. Other tints are not changed. holzBar reads the two options through public macOS API and listens for their change only while System Glass is in use or the Shelf is open, so nothing polls and no permission is needed.
- **Settings → Appearance says what System Glass does** under these two options, in English, German, French, Italian and Romansh.

### 🔄 Changed
- **Settings sync is removed.** Anyone who had it turned on in 0.0.6 or 0.0.7 beta 1 no longer syncs: this Mac neither sends its settings nor takes settings from another Mac. Nothing was deleted: your stored settings are untouched, and so is the file in your sync folder. Use **Export…** and **Import…** to carry settings between Macs until sync returns.
- **The macOS 27 Liquid Glass slider is not followed.** macOS 27's SDK offers no public signal for it (holzBar checked the AppKit, SwiftUI and Accessibility headers), and holzBar uses no private API and reads no system preference files. Only Reduce Transparency and Increase Contrast are followed.

### ⚠️ Known issues
- **The opaque treatment has not yet been checked on real macOS 26 and 27 systems by the maintainer.** Its decision logic has unit tests, but how it looks, that the application menu and the items stay visible and clickable, and the live switch still need hands-on testing. Please report anything that looks wrong on the [issue tracker](https://github.com/holzcloud/holzBar/issues).
- **Native support for macOS 27's own overflow button is not part of this beta.** It comes in a later 0.0.7 beta; until then holzBar does not cooperate with that button.
- **Macs still on 0.0.6 or 0.0.7 beta 1 keep syncing** through the sync folder with each other, and a Mac on this beta no longer takes part. Update them as well, or use **Export…** and **Import…**.
- The other known issues of beta 2 and 0.0.6 still apply.

### 📦 Install
Update an installed holzBar:
```sh
brew update && brew upgrade --cask holzbar
```

New install (quit the original Ice, Thaw, Bartender or Hidden Bar first if one of them is running):
```sh
brew tap holzcloud/holzbar https://github.com/holzcloud/holzBar
brew trust --cask holzcloud/holzbar/holzbar
brew install --cask holzbar
```

If macOS says holzBar can't be opened, take it out of quarantine and open it again:
```sh
xattr -dr com.apple.quarantine /Applications/holzBar.app
```

Releases before 1.0 are pre-releases. This release is signed with the same certificate as 0.0.6 and 0.0.7 beta 1 and 2, so updating keeps the Accessibility and Screen Recording permissions. Coming from 0.0.5, follow "Install and update" in the [0.0.6 notes](https://github.com/holzcloud/holzBar/releases/tag/v0.0.6).

holzBar runs on macOS 14 Sonoma and later, up to macOS 27.
